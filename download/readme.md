# Download BonBon

### Windows download

Download and expand [this zip file](https://github.com/Latz/BonBon-Windows/releases/latest/download/windows.zip).

It contains one folder, BonBon, which contains `bonbon.exe` plus the files it needs beside it. Keep them together, and launch `bonbon.exe`.

When you run it the first time, Windows may say "Windows protected your PC". BonBon for Windows isn't signed with a code-signing certificate yet, so SmartScreen doesn't know it. Click "More info", then "Run anyway". You only have to do this once.

BonBon needs the WebView2 Runtime, which Windows 10 and 11 usually already have. If yours doesn't, get it from [Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).

Note: The Windows build runs only on 64-bit Intel-type chips (x64).

### Macintosh download

Download and expand [this zip file](https://github.com/scripting/bonBon/releases/latest/download/mac.zip).

It contains one file, BonBon.

When you run the app, the Mac OS will require that you approve the download before you can run it.

If your Mac says BonBon is damaged. It isn't damaged. BonBon isn't signed with an Apple developer certificate yet, so macOS won't open it after it's downloaded, and tells you to move it to the Trash. Instead, open the Terminal app, type `xattr -r -d com.apple.quarantine` followed by a space, drag the BonBon app into the Terminal window so its path is added to the line, and press Return. After that BonBon opens normally. You only have to do this once for each copy you download. 

Note: The Mac build runs only on Apple silicon.

### Linux download

Download and expand [this zip file](https://github.com/scripting/bonBon/releases/latest/download/linux.zip).

It contains one folder, BonBon, which contains the program plus the files it needs beside it.

Launch it as you would any other desktop app.

Note: The Linux build runs only on Intel-type chips.
